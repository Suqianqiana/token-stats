## 0. 一句话结论

把"卡片"从「背景块 + 边框 + 圆角」降级为**「靠细线分区的段落」**。技术上**只需一个注入点**
（`paint_pod()`）+ 若干处 2~6 行的分支，即可覆盖全站 **17 张卡片**；风险不在机制、而在**版面节奏**，
所以先只做一页出图给你确认，再推全站。

## 2. 关键勘察结论（决定这个方案可行性）

| 发现 | 位置 | 含义 |
|---|---|---|
| 主底板**已有**独立绘制 + **已画侧栏竖直分隔线** | `LiquidGlassFrame.paintEvent`（line 317，`sep_x`） | 参考图那块"整板"我们已经有了；毛玻璃只需"把板内的卡片拆掉" |
| `paint_pod()` **全程序只有 2 个调用点** | `GlassPodFrame.paintEvent`(403) / `GlassDialog`(598) | 加一个 `role` 参数即可精确区分「页面分区（拆）」与「浮层弹窗（留）」——**这是本方案的地基** |
| 卡片类只有 4 个 | `GlassPodFrame` / `StatCard` / `SNSyncPanel` / `SNPromoCard`（后两个继承前者） | 17 处实例化全部经由同一底板，改一处即全覆盖 |
| 需单独分支的自绘元素 | `BarIndicator`(7 处) / `StatRankRow`(斑马纹+环形) / `MachineBox._paint_shell` / `MachineRow`(外壳) / `ModelRow`(斑马纹) / `StackedBarChart` / 热力图 | 数量有限、每处 2~6 行，可穷举 |
| 顶部区间按钮样式集中在**一处** QSS | `apply_styles()` 5244-5250 | 可整体换成参考图的"容器 + 药丸"分段控件 |
| 主题开关已有**成熟链路** | `set_dark()` / `set_glass()` → `_refresh_subpages_theme()` | 毛玻璃照抄这套，不必新造刷新机制 |

## 3. 核心方案：毛玻璃 = **"分区语言"开关**，不是第四套配色

- 新增 `theme_state["frost"] = bool`（**放进去即自动落盘** —— 吸取第 58 轮"迁移标记位必须进
  `theme_state`，否则一保存就丢"的教训）。
- **毛玻璃不改调色板**，仍走现有深/浅色板；它只改**绘制结构与分割方式**：

| 对象 | 现有 | 毛玻璃模式 |
|---|---|---|
| 页面区块（`GlassPodFrame`） | 圆角 12 + 填充 + 菲涅尔描边 | **只留顶部 1px 细线**（深色用白线低透明 / 浅色用 `BORDER`） |
| 浮层弹窗（`GlassDialog`） | 玻璃卡 | **保持不变**（浮层必须实体，否则会"看不见"） |
| 主底板（`LiquidGlassFrame`） | 玻璃板 + 侧栏竖线 | 保留，仅微调 alpha / 描边强度 |
| 区块头彩色细条（`BarIndicator`） | 蓝/绿/黄/紫 16×4 | 降为**中性**（或隐藏） |
| 列表斑马纹 | 有 | **关闭** |
| 按钮 | primary 实心蓝 / ghost 描边 | ghost 更淡（透明 + 细线），primary 保留蓝 |
| 区间切换 | 4 个独立按钮，选中蓝底 | **容器 + 药丸**（对应参考图的 DAY / MONTH / TOTAL） |

- **可与深色/浅色自由叠加**；推荐搭配深色 = 参考图效果。
- 打开毛玻璃时**自动一并打开「液态玻璃」**（否则没有半透明质感），之后仍可单独关掉。

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **版面发虚**：17 张卡同时去掉边框后，段落之间缺少视觉锚点 | 页面可能"散掉" | 三件套兜底：**段间距 + 1px 细线 + 小号灰标题**；先只做 WB 页出图复核 |
| **浅色模式细线对比不足** | 分区看不见 | 细线色随主题走两套 alpha（深色白线 / 浅色 `BORDER`），并单出一张浅色毛玻璃图验收 |
| **误伤弹窗**（弹窗也是 `paint_pod` 画的） | 弹窗变透明 → 文字糊在背景上 | `role` 显式区分 + **加断言**（毛玻璃下弹窗仍必须填充） |
| **主题刷新遗漏**（某些子页不跟着变） | 切换后花花绿绿 | 复用 `set_glass` 的刷新链路；出图覆盖 **深/浅 × 毛玻璃** 共 4 种组合 |
| **回归被打破** | 已有 301 项断言 | 改前后各跑一遍，**必须全绿**；新增断言守住新行为 |
| **改动面大、方向可能不合口味** | 返工 | 分两步交付：**先 WB 页出图给你看**，确认后再推商汤/多机页 |

## 6. 验收方式

1. **备份**：改前对 `token-stats/` 做整目录副本（沿用既有 `_backup/` 做法）+ 版本标签。
2. **出图复核**（offscreen 渲染，合成匿名数据）：
   - `WB 页 · 毛玻璃·深色` / `商汤页 · 毛玻璃·深色` / `多机页 · 毛玻璃·深色`
   - `WB 页 · 毛玻璃·浅色`（验证浅色细线对比）
   - `WB 页 · 现有深色`（对照，看"卡片 vs 细线"差异）
3. **回归**：301 项必须全绿，并新增断言：
   - `paint_pod(role="section")` 在毛玻璃下**不填充**（把 pod 画到已知底色的 `QImage` 上，中心像素 == 底色）
   - `role="panel"`（弹窗）**仍然填充**（中心像素 != 底色）
   - 打开毛玻璃 → `theme_state["frost"]` 为真**且落盘**（读回 `settings.json` 校验）
   - 毛玻璃不破坏既有结构不变量（行数 / 行高 / 页高贴合，用 `sizeHint()` 比对，不 show）
4. **实机**：重启应用，由你亲眼确认。
