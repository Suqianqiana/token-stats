方案做法优点取舍
A 主次分层 合计 Token 做成主指标（超大数字 + 涨幅 + 趋势线），其余三项降为右侧竖排小行 层级最强，一眼知道"核心数字是谁"；省下的横向空间让主数字能更大 次要三项字号变小，扫读速度略降
B 四列+趋势 保留四等分，每张加 14 天迷你趋势线 + 环比 chip 信息密度最高；四项都有"走势"，横向四列仍整齐对齐 元素最多，毛玻璃的克制感会减弱一点
C 单排指标带 去掉分区块，四组"标签在上/数字在下"，只用竖细线分隔 最克制、最省垂直空间，下面的图表和热力图能更高 四项完全平级，没有主次（想强调总量时不突出）
